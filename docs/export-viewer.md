# 导出数据 viewer

本地 viewer 只读取 [目标格式数据契约](export-contract.md) v2.x 的导出目录。不读取原始数据集、转换脚本或机器人模型；增加数据源无需修改 viewer。

```bash
pip install -e '.[viewer]'
python scripts/viewer/export_viewer.py path/to/exported-dataset
```

打开终端给出的 `http://127.0.0.1:8765/`。可用 `--host`、`--port` 指定监听地址和端口。

页面可选择 episode、拖动共享时间轴或以 1× 速度播放。每路 state 和相机独立按自身的 `timestamp_ns` 取当前时间之前最近的样本；时间点早于首样本时留空，不做插值。相机按索引的 `frame_index` 解码 MP4 显示顺序中的帧，MP4 容器时间不参与采集时间计算。相机画面旁分别显示左右臂的 3D TCP 当前位姿及短拖尾，默认只保留之前 2 秒的原生样本，可切换为 0.5 或 5 秒。拖尾颜色从淡到亮指向当前位姿，不绘制更早或未来的轨迹。红 X、绿 Y、蓝 Z 为工具轴，白色线段示意夹爪开合。可拖动旋转、滚轮缩放、重置视角。指令按元数据里的生效区间高亮。

左右臂各自处于契约规定的固定参考系；契约不保证两个参考系相同，也没有相机外参，因此 viewer 不做跨臂空间拼接或视频上的 3D 叠加。画面与位姿通过共享时间轴对应。

逐帧图像由 PyAV 解码并通过 Pillow 转成 JPEG。倒退或切换相机时，简单实现会从视频开头重新解码；长视频的远距离跳转可能较慢。viewer 仅在本机监听，面向人工检查单个导出目录。
