# 导出数据异常检测规则

## 异常记录格式

每条异常对应一个时间区间，只记录定位与原因，不写具体数值细节，避免占用存储。结果为 JSONL，每行一条：

- `index`：异常所在 episode 在 `episodes.jsonl` 中的行号，从 0 开始。
- `stream`：异常所在的数据流，取 `left_eef`、`right_eef`、`left_gripper`、`right_gripper` 之一。
- `start_ns`、`end_ns`：异常区间 `[start_ns, end_ns)`；单点异常取相同的起止值。
- `reason`：规则标识，如 `boundary_idle`。

示例：`{"index": 3, "stream": "left_eef", "start_ns": 0, "end_ns": 4100000000, "reason": "boundary_idle"}`

## 规则 1：首尾静止过长（`boundary_idle`）

先判断每个样本相对边界样本是否「变化」：

- EEF 位姿：位置变化超过 1 cm，或朝向变化超过 5°，即为变化。
- 夹爪：开合变化超过 0.05，即为变化。

再对每一路流分别计算：

- 开头静止时长：episode 起点到该路第一次变化的时刻；整段无变化则取整段时长。
- 结尾静止时长：该路最后一次变化的时刻到 episode 终点；整段无变化则取整段时长。

四路取最小值：只要有一路在动，就认为 episode 已经开始或尚未结束，避免单臂长期不动被误判。
开头或结尾静止时长超过 3 秒，判为异常。开头超时记录区间 `[0, 开头静止时长)`；结尾超时记录区间
`[整段时长 - 结尾静止时长, 整段时长)`；两端都超时记两条。
每条记录的 `stream` 取决定该端静止时长的那一路：开头取最早开始运动的一路，结尾取最晚停止运动的一路。

1 cm、5°、0.05、3 秒均为默认阈值，可覆盖配置（位置容差、朝向容差、开合容差、最大静止时长）。

## 规则 2：State 明显突变（`state_jump`）

四路 state 独立检测，保留原生采样点。EEF 取任意两个样本 `a < b`，夹爪只取相邻样本 `b = a + 1`；
若时间间隔不超过 50 ms，就把 `[a, b]`
当作候选变化，再分别用 `a` 之前、`b` 之后各 100 ms 的上下文估计该处的正常运动速度：

- 每侧在窗口的 0%、25%、50%、75%、100% 处取最近的原始样本，等距取较晚样本，边界样本可略微超出窗口。
- 所选样本两两配对，去掉重复配对和零时间差配对，每对按「变化距离 ÷ 实际时间差」算速度，取中位数作为该侧基准。
- 同一物理分量取前后两侧基准中较大的一个。

夹爪快速开合前后常接近静止，不能仅凭短时间内累计开合幅度大就判为突变。因此夹爪还计算候选紧邻的
前一段、后一段速度，均使用实际时间差；只计入与候选同方向、且采样间隔不超过 50 ms 的段。
这两段速度的绝对值之和作为局部运动基准，再与上述上下文基准取最大值。两侧相加为连续开合的速度峰值
留出余量；反向变化不提供基准，避免尖峰及其恢复互相掩盖。夹爪不把跨多个样本的累计变化作为候选，
从而避免把已采样到的快速连续开合整体判为跳变。EEF 仍按上述多样本候选规则检测。

位置距离取三维欧氏距离（米），朝向距离取 rotation6D 还原后的 SO(3) 最短旋转角（度），夹爪距离取
`openness` 差的绝对值，三者分别计算。候选的变化距离记为 `D`、时长记为 `Δt`、基准速度为 `v`，
当 `D - v · Δt` 超过额外幅度阈值、且 `D` 超过 `v · Δt` 的 3 倍时判为异常；位置、朝向、夹爪的额外幅度阈值
默认分别为 2 cm、10°、0.15，独立于静止检测容差，比较用严格大于。

同一终点只保留最短的合格候选，再去掉包含已有合格候选的更宽区间；候选 `[a, b]` 输出为 `[t_(a+1), t_(b+1))`。
同一路重叠或相隔不超过 50 ms 的区间合并，位置和朝向共同触发只记一条 `state_jump`；重复时间戳只保留最后一个值，
与 viewer 取样一致。每侧必须具备完整的 100 ms 上下文，选中至少 3 个不同时间戳且跨度达到 75 ms，
上下文或候选内相邻采样间隔超过 50 ms 时跳过该候选。流首尾、过低采样率、短流或缺失数据附近无法判断。
若开合几乎全部落在一个采样间隔内，仍可能与真实阶跃无法区分；此规则是待复核的异常候选检测，不能证明物理不连续。

50 ms、100 ms、3 倍和三项额外幅度阈值均可覆盖配置；要求 50 ms 至少 1 ns、100 ms 至少为其两倍、
3 倍大于 1，三项额外幅度阈值有限且非负。

## 规则 3：中段静止过长（`internal_idle`）

规则 1 只覆盖 episode 首尾，本规则覆盖中间：四路 state 同时不变的区间。判定「变化」的容差与规则 1 相同
（EEF 位置变化超过 1 cm 或朝向变化超过 5°；夹爪开合变化超过 0.05）。

逐路以首个样本作为参考，顺序比较后续样本与参考状态；超过任一容差时，记该样本时刻为变化时刻，
并将参考更新为该样本。未超过容差时保持参考不变，首个样本不计为变化。这样连续的小幅运动会相对参考
累积到超过容差，不会因为单帧变化小而漏掉；容差内的往返噪声也不会被当作累计路程。
重复时间戳只保留最后一个值，与 viewer 取样一致。

把四路的变化时刻合并成一个升序序列。相邻两个变化时刻 `t_a < t_b` 之间没有任何一路偏离自身参考状态超过容差，
故 `[t_a, t_b)` 为容差意义上的四路同时静止区间。

- 该区间两端都是变化时刻，天然位于 episode 中段，不覆盖首尾（首尾由规则 1 负责）。整段没有任何变化时刻时
  不存在中段区间，不记录。
- `t_b - t_a` 超过最大中段静止时长即判为异常，记区间 `[t_a, t_b)`。
- 只要有一路持续运动并在最大静止时长内偏离参考超过容差，就不会触发本规则，即使相邻帧变化均小于容差。
  低于容差的微小运动仍视为静止；区间边界取首次超过容差的原生样本时间，不代表精确的物理启停时刻。

因该区间是四路共同静止，没有单一路能代表，故每条区间按四路各记一条：`stream` 分别取四路之一，
`start_ns = t_a`、`end_ns = t_b`，`reason` 为 `internal_idle`。

1 cm、5°、0.05、最大中段静止时长默认 10 秒，可覆盖配置（前三项容差与规则 1 共用）。
